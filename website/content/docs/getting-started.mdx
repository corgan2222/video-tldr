## Clone

```bash
git clone https://github.com/corgan2222/video-tldr.git
cd video-tldr
```

## Build

The exact build, test and lint commands live in the repository's own
[README](https://github.com/corgan2222/video-tldr#readme) and `AGENTS.md` — they depend on the
language and tooling this project uses. Once the project builds, this page
is a good place to add anything a newcomer needs beyond that.
