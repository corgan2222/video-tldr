video-tldr is two parts. A local service fetches the video, transcribes it
when there are no captions, and writes the summary. A browser extension
talks to that service over `127.0.0.1`. Nothing leaves the machine except
what your chosen language model backend sends.

## Install the service

The service comes from a release and needs
[uv](https://docs.astral.sh/uv/), which carries its own Python:

```powershell
irm https://raw.githubusercontent.com/corgan2222/video-tldr/main/install.ps1 | iex
```

That picks the CUDA libraries when the machine has an NVIDIA card and the
ONNX runtime alone when it has none, then puts `video-tldr` on your PATH.
The speech models download on first use, several gigabytes of them.

`-Root D:\video-tldr` keeps the program, its environment and its data
under one directory instead of three standard places.

## Install the extension

The extension is the `.zip` attached to the same release. In Firefox,
load it as a temporary add-on through `about:debugging` ("This Firefox").
In Chrome, unpack it and load the folder through `chrome://extensions`
with developer mode on.

## Run it

The installer registers no autostart. Start the service yourself:

```powershell
video-tldr serve
```

If you would rather not think about it again, let a logon task do it:

```powershell
video-tldr autostart on
```

`video-tldr autostart off` takes it back, `status` says which it is, and
`install.ps1 -Autostart` sets it up during the install.

Then click the toolbar icon, open Settings, press Connect, and choose the
language, the outputs and the model. Open a YouTube video, click the icon
and press Fast or Thorough.

Whenever the service is not answering, the extension says so and shows
the command with a button that copies it.

Without a browser, `video-tldr run <url>` does the same from the command
line.

## Build from source

Until the first release is published, both parts come from the
repository:

```bash
git clone https://github.com/corgan2222/video-tldr.git
cd video-tldr
npm ci
npm run build
```

Load `dist/` as the extension, and run the service with
`uv run --project service video-tldr serve`. The
[service README](https://github.com/corgan2222/video-tldr/blob/main/service/README.md)
covers its setup and the model choice.
