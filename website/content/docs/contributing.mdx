This project takes changes through pull requests at
[https://github.com/corgan2222/video-tldr](https://github.com/corgan2222/video-tldr); nothing lands on `main` directly. The
ground rules are in
[CONTRIBUTING.md](https://github.com/corgan2222/video-tldr/blob/main/CONTRIBUTING.md).

## AI tools

Whoever maintains this project may use AI tools when writing code: drafting,
refactoring, tests, documentation. They read everything before it lands; the
details are in
[AI_POLICY.md](https://github.com/corgan2222/video-tldr/blob/main/AI_POLICY.md).

Contributors may use whatever tools help them, with one limit: you must be
able to explain every line of your diff.
